# 🎮 Simon Game - HTML, CSS & JavaScript

A fun and interactive **memory-based Simon Game** built using **HTML, CSS, and vanilla JavaScript**.  
The game lights up a random sequence of colored buttons, and the player must repeat the exact pattern.  
Each successful round increases the sequence length and difficulty.

---

## 📌 Features

- ✔ Four-color interactive buttons  
- ✔ Random sequence generation  
- ✔ Level-based difficulty progression  
- ✔ Sound effects for each button  
- ✔ Game over animation and restart option  
- ✔ Works on all modern browsers  
- ✔ Fully responsive UI  

---

## 🧠 How the Game Works

1. Press any key (or the Start button if added) to begin the game.
2. A random color will flash with a sound.
3. You must click the same color.
4. Each level adds a new random color to the pattern.
5. If you press the wrong button → **Game Over**.
6. Game resets and you can start again.
